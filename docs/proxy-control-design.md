# Mihomo 代理控制页设计约定

## 产品意图

- 用户：通过 SSH 管理单台服务器的操作者。
- 主要任务：确认服务状态；在规则、全局、直连模式间切换；查看 AUTO 当前线路；搜索并手动选择节点；刷新订阅。
- 期望品质：冷静、精确、紧凑、可信、可逆。
- 拒绝品质：公开控制端口、装饰性渐变、泛滥发光、卡片堆叠、仅靠颜色表达状态、隐藏高影响操作。
- 方向：S5 Monochrome Precision。使用单一状态绿表示在线、选中、主要确认；警告和错误只用于对应语义。

## 安全边界

- Web 服务默认绑定 `127.0.0.1:8790`，只通过 SSH 本地端口转发访问。
- Mihomo 继续只通过 `/run/mihomo/controller.sock` 提供控制，不新增 TCP 控制端口或 UFW 规则。
- 所有更改请求要求 JSON 与同源 `Origin`；Host 只接受 loopback 名称，防止跨站请求和 DNS rebinding。
- 页面只返回节点名称、协议、可用状态和延迟；不返回订阅 URL、节点地址、端口、密码、配额或 Mihomo 原始配置。

## 视觉与布局

- 字体：系统无衬线用于界面，系统等宽用于数字和技术标签；标题 18px，主体 12px，标签 10–11px。
- 色彩：近黑背景、冷灰表面、白色主文字、灰色辅助文字；状态绿、警告黄、错误红。
- 间距：4/8/12/16/24/32/48px；半径 6/10/14px；仅用细边框与少量浮层阴影。
- 桌面：1180px 内容宽度，三项指标、两列控制区、密集节点表格。
- 平板：控制区单列，节点表保持表格。
- 手机：指标两列重排、模式纵向排列、节点表转换为卡片列表，无横向页面滚动。

## 组件与状态

- 模式选择：radio 语义；全局和直连在提交前出现确认对话框，规则模式可直接恢复。
- 节点选择：AUTO 固定在表格上方；具体节点显示名称、协议、可用状态、延迟和当前选择。
- 搜索：按节点名称或协议实时过滤，支持空结果状态。
- 状态：加载骨架、在线、失败提示、保存中、保存成功 toast、按钮禁用和订阅刷新状态。
- 键盘与可访问性：逻辑 Tab 顺序、可见焦点、原生 dialog、ARIA 状态/选中标记，状态同时使用文字和图形。
- 动效：120ms 功能性反馈；遵循 `prefers-reduced-motion`。

## 验证视口

- 桌面：1440×900。
- 平板：820×900。
- 手机：390×844。
- 检查：无文本裁切、无横向滚动、选择/禁用/焦点清晰、确认对话框可操作、加载/空/错误状态属于同一视觉系统。
