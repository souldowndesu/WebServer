# 前端实现交接与基础设计契约

这份说明交给后续负责正式交互与美术的 AI。后端已实现，测试 UI 不属于产品源码。不要恢复旧时钟、匿名聊天室、独立代理页面或任何未登录直达管理功能。

## 冻结的信息架构

登录后使用一个稳定的应用外壳：

1. 概览：个人身份、最近同步、连接申请、任务状态；不做装饰性统计大屏。
2. 规划：结构对应 IrohaWalendar 的命令栏、目标/行动与日常规划侧栏、日/周/月、统计；所有实体控件只读，明显显示桌面同步来源与最后更新时间。
3. 通讯：账号池、申请、已连接列表和会话阅读/撰写；备注只对当前账号可见。
4. 博客：结构化图文预览、自己的编辑入口、自定义网页审核状态、其他账号博客观察。
5. 推理任务：新任务表单、参数分组、队列表、阶段、进度、结果；不要暗示服务器本身执行模型。
6. 代理：状态对所有登录用户可见；全局修改控件仅管理员显示，个人偏好与全局状态必须视觉区分。
7. 设置：资料、昵称、头像、主题、同步设备；管理员另有账号池、博客审核和监控端管理。

## 选定视觉方向

使用 `S5 Monochrome Precision` 作为主系统，原因是设置、任务、代理和账号管理都需要冷静、高密度、可扫描。结构性借用：

- 规划场景借用 `S4 Workspace Utility` 的日历与命令栏，但仍使用 S5 令牌；
- 通讯借用 `S7` 的安静阅读宽度和非气泡式分隔，不使用光谱渐变或发光；
- 博客借用 `S6 Editorial Workspace` 的阅读节奏；
- 登录与确认弹窗使用 `S2` 的层级深度，但保持实色中性背景。

拒绝：紫蓝 AI 渐变、玻璃铺满全站、发光边缘、巨型口号、每个区块一张圆角卡、装饰性图表、仅靠颜色表达状态、低对比暗色、聊天气泡瀑布。

## 令牌

- 字体：系统 UI sans；数字、id、延迟和时间使用系统 monospace。字级 11/12/13/14/16/20/28/36px。
- 浅色：背景 `#F7F8FA`、画布 `#FFFFFF`、强文字 `#111318`、弱文字 `#626975`、边线 `#DDE1E7`。
- 深色：背景 `#101216`、画布 `#15181D`、强文字 `#F2F4F7`、弱文字 `#9AA2AE`、边线 `#2A2F37`。
- 强调：中性偏蓝 `#315EFB` 只用于主要动作、当前选择和焦点；成功 `#16845B`、警告 `#B26A00`、错误 `#C43B3B`。
- 间距：4/8/12/16/20/24/32/48px。半径：4px 数据单元、7px 输入/按钮、10px 浮层、14px 登录容器。阴影只用于浮层。
- 控件高度：紧凑 32px、默认 38px、触控 44px。图标统一使用一个真实 SVG 家族，16/20px。
- 动效：90/140/200ms，功能性淡入/位移；`prefers-reduced-motion` 时取消位移。

## 布局与响应式

- ≥1180px：240px 可折叠侧栏，主内容最大 1440px；规划允许第二层库侧栏和日历网格。
- 760–1179px：导航折叠成 64px rail 或 drawer；表格保留关键列，详情进入侧面板。
- <760px：单主列与底部/抽屉导航；日历默认日/三日摘要，周视图允许内部横向滚动但页面不得横向滚动；表格转列表。
- 只有消息列表、日历网格和数据表拥有局部滚动；页面不能出现含糊的双重滚动。

## 必须实现的状态

登录错误/限速、加载、空、只读、无权限、保存中、成功、服务器错误、长昵称、缺头像、很多用户、待处理申请、断开连接、长消息、消息被容量策略清理提示、日历未同步/同步过期/设备撤销、博客待审/拒绝/通过、自定义页面沙箱、任务排队/运行/租约重试/成功/失败/取消、代理离线、全局更改确认、管理员专属操作和破坏性确认。

键盘：完整 Tab 顺序、可见 focus-visible、Esc 关闭浮层、dialog 焦点圈闭、会话 composer 多行行为、表格/日历可到达。所有状态必须有文字或图形，不只靠色相。

## 可直接交给前端 AI 的提示

> 使用本仓库 `docs/frontend-handoff.md`、`docs/api-v1.md` 和 `BACKEND_GUIDE.md` 实现正式网页前端。先冻结这里的信息架构和真实中文内容，再建立设计令牌、原语和应用外壳，然后只完成登录 + 规划只读页 + 通讯页作为 pilot。主系统必须是 S5 Monochrome Precision；日历仅借用 S4 结构、通讯仅借用 S7 阅读构图、博客仅借用 S6 阅读节奏，全部重新套用同一令牌。不要使用紫蓝渐变、泛滥玻璃/发光、巨型营销标题、卡片堆叠、emoji 图标或装饰性图表。API 会话只保存在 HttpOnly cookie/内存，不写 localStorage；cookie 修改请求带 CSRF token。实现桌面 1440×900、平板 820×900、手机 390×844，覆盖加载、空、错误、权限、只读、长内容和确认状态并提交截图 QA。不得添加旧 `/api/messages`、时钟、匿名入口，也不得让普通用户看到代理全局修改、账号管理、博客审核或 Worker token 控件。

## 本次本地 QA 约束

本次基础 UI 仅用于验证上述方向，在操作者本地忽略目录生成和截图。它不能被复制到 `control_plane`、不能加入 Git、不能作为正式组件实现；后端根路径会明确返回 `ui_bundled:false`。
