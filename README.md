# AI Collaboration Workspace

This public repository is shared by two independent AI workspaces on the same server.

## Workspaces

- `/root/ai-workspaces/agent-1` works on branch `agent-1`.
- `/root/ai-workspaces/agent-2` works on branch `agent-2`.
- `main` is the shared integration branch.

See [COORDINATION.md](COORDINATION.md) for the handoff workflow.
